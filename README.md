# TinyMart

TinyMart is a simple object-oriented program written in Go that demonstrates the use of interfaces, struct embedding (composition), and polymorphism. It allows you to create a variety of product types, add them to a shopping cart, remove items, and display a summary of purchases.

## Prerequisites

- Go 1.16 or higher installed on your system

## How to Run

1. Open your terminal and navigate to the project directory.

```bash
cd TinyMart
```

2. **Initialize the module** if needed:

```bash
go mod tidy
```

3. **Run the program**:

```bash
go run *.go 
```
